**Why start here**

Choosing a single-purpose build before you know which module you actually use is
backwards. This one lets you switch components off one at a time and find the
combination that fits how you play, rather than guessing from a feature list.

**First run, in order**

1. Extract to a folder you own — not `Program Files`, not a downloads folder.
2. Right-click the loader, run as administrator.
3. Let the updater finish before opening any tab.
4. Start with everything off.
5. Enable one module per session and note what it changes.
6. Save the combination that works.

**The honest trade-off**

Every module enabled is more work for the same frame budget. A build with six things
running will cost frames that a single-purpose build does not. If frame stability
matters, this is the wrong starting point — pick the one module you want instead.

**What this is not**

It is not a fix for a banned account. Account bans are account-level. The identity
reset only helps when the ban is tied to hardware, and it helps the *next* account,
not the banned one.

**Order of operations**

1. Close the game and its launcher completely.
2. Run the loader as administrator.
3. Open the **Spoofer** tab and press **Spoof**.
4. **Reboot** — volume serial and SMBIOS are read at boot.
5. Create a fresh account and log in.

**What it does not do**

It does not unban the old account. It gives the machine a new identity so a new
account is not linked to the old ban.

**Skipping the reboot is the most common mistake** — people report "the spoofer
did nothing" when they simply never restarted.
